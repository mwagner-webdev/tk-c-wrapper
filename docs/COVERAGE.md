# Coverage and test results

The detailed per-class tables are in
[COVERAGE_TABLES.md](COVERAGE_TABLES.md), generated by
`tools/coverage_summary.tcl` from the extraction pipeline and the
behavioural record the test suite writes (`build/<ver>/behavior_coverage.txt`).
The machine-readable report is `generated/coverage.json`, which lists
every option and subcommand with status, approach, provenance and
reasons.

## Selected widget sample (Tk 9.1.0)

The sample is `toplevel` and `frame` (classic), `ttk::frame`, `ttk::label`,
`ttk::button`, `ttk::entry` and `ttk::treeview` (ttk), plus `grid` and
`pack`.

By approach: 235 functions use declarative tables only, 86 use inferred

label of each function is in `generated/api.json` and in the comment above
each prototype in `include/tkx_generated.h`.

## All discovered classes (what the generator *could* do)

Code is emitted only for the selected classes.  The classification is
computed for all 22 classes found in the 9.1.0 sources:

- **Options:** 321 discovered.  236 can have typed read/write accessors,
  31 read-only, 1 callback, 6 are aliases, 44 are excluded by overlays
  (mostly `-textvariable`/`-variable`, scroll commands, `-takefocus`), and
  3 are unsupported (`TK_OPTION_CUSTOM -locale`).  So 268 of 315
  non-alias options (85 %) need no further metadata.
- **Subcommands:** 243 discovered.  71 have complete evidence and could
  be generated without metadata, 107 are partial, 21 take Tcl scripts
  (never generated) and 44 are `cget`/`configure`.

**Reproducibility check.**  A fresh clone of commit `2963e00` was built
from nothing with `make deps && make && make check-generated && make test`
(Tcl/Tk downloaded, verified and compiled; library, bridge and examples
built; no generated-file drift).  All 151 tests passed; the one test added
later (`lifecycle-1.6`) is included in the numbers above.

Geometry assertions compare sizes relative to each other (e.g. "the extra
space is shared 1:3") or use widgets with fixed pixel sizes.  The only
font-dependent comparison is tkx against plain Tk in the same process,
which must agree exactly.
